# CloudOps Lite Platform

A lightweight production-inspired CloudOps platform built on Ubuntu Server using k3s, GitOps, CI/CD, monitoring and secure deployment practices.

## Local Environment

- Ubuntu Server
- k3s single-node Kubernetes
- Traefik Ingress
- FastAPI CloudOps API
- Flux CD GitOps

## Current Status

- k3s installed
- CloudOps API deployed
- Traefik Ingress configured
- Preparing GitOps with Flux CD
